# 포트폴리오 2호 — CWRU 베어링 결함 분류 (RandomForest)

**진동 신호 → 시간영역 특징 추출 → ML 결함 분류 → 결함 크기 교차 검증**

---

## 개요

CWRU(Case Western Reserve University) 베어링 진동 데이터셋을 이용해  
시간영역 특징 7종을 추출하고 RandomForest로 4가지 결함 상태를 분류했다.  
단순 분류에 그치지 않고 **결함 크기 교차 검증**으로 실제 현장과 유사한 조건에서 모델의 한계까지 확인했다.

---

## 데이터

| 항목 | 내용 |
|------|------|
| 출처 | CWRU Bearing Data Center (공개 데이터) |
| 샘플링 주파수 | 12,000 Hz |
| 결함 종류 | 정상(Normal) / 내륜(IR) / 외륜(OR) / 볼(Ball) |
| 학습 데이터 | 결함 크기 0.007인치 |
| 교차 검증 데이터 | 결함 크기 0.014인치 (학습 시 미사용) |

---

## 분석 과정

### 1. 특징 추출 (시간영역 7종)

진동 신호를 1024샘플(~85ms) 윈도우로 세그먼트 분할 후 각 세그먼트에서 특징 추출.

| 특징 | 의미 |
|------|------|
| RMS | 진동 에너지 |
| Peak | 순간 최댓값 |
| Peak-to-Peak | 진동 폭 |
| Crest Factor | Peak/RMS — 충격성 |
| **Kurtosis** | **분포 뾰족함 — 충격 강도** |
| Skewness | 비대칭성 |
| Shape Factor | RMS/평균절댓값 |

**Kurtosis 결과: OR(7.6) > IR(5.4) >> Ball(3.0) ≈ Normal(2.8)**  
외륜 결함이 가장 높은 이유: 외륜은 고정되어 있어 볼이 항상 같은 지점(6시 방향 하중대)을 강타 → 가장 일정하고 강한 충격 발생.

### 2. Data Leakage 방지

50% 겹침 세그먼트를 랜덤 분할하면 학습/테스트 간 인접 구간이 섞여 100% 허위 정확도가 발생한다.  
→ **신호 앞 70% 학습, 뒤 30% 테스트**로 물리적 분리.

### 3. 분류 및 교차 검증

| 평가 조건 | 정확도 | F1(macro) |
|----------|--------|-----------|
| 동일 조건 (0.007" → 0.007") | 100% | 1.000 |
| **교차 검증 (0.007" → 0.014")** | **62.5%** | **0.530** |

#### 교차 검증 클래스별 결과

| 결함 | Precision | Recall | 분석 |
|------|-----------|--------|------|
| Normal | 0.74 | 1.00 | 정상 패턴은 크기 무관 안정적 인식 |
| IR (내륜) | 0.67 | 1.00 | 내륜 패턴도 비교적 일반화됨 |
| Ball (볼) | 0.43 | 0.50 | 부분 인식 |
| **OR (외륜)** | **0.00** | **0.00** | **완전 미인식** |

---

## 핵심 발견 — OR 0%의 의미

0.007인치 OR 학습 시 모델이 학습한 특징 범위: **RMS ~0.67g, Kurtosis ~7.6**  
0.014인치 OR 테스트 시: **RMS ~1.5g 이상** → 학습 범위를 완전히 벗어남

모델이 "외륜 결함의 물리적 패턴"을 배운 게 아니라 **특정 결함 크기의 수치 범위를 암기**한 것.  
이는 버그가 아니라 단일 조건 학습 모델의 구조적 한계를 보여주는 결과다.

> **실제 현장에서는 결함이 서서히 커진다.**  
> 0.007인치로 학습한 모델은 0.014인치에서 외륜 결함을 전혀 감지하지 못한다.

---

## 개선 방향

1. **다양한 결함 크기 혼합 학습** — 0.007" + 0.014" + 0.021" 통합
2. **특징 정규화** — 절대값 대신 기준값 대비 상대값 사용
3. **FFT 주파수 특징 추가** — 결함 크기와 무관한 BPFO/BPFI 주파수 패턴 활용
